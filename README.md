Tricordarr
==========

A [Twitarr](https://github.com/jocosocial/swiftarr) client.

Quick Start
-----------

```bash
nvm install lts/jod # v22.18.0
nvm use lts/jod

npm clean-install

# Android (Mac, Windows, Linux)
npx expo run:android

# iOS (Mac)
npx pod-install
npx expo run:ios --scheme Development # or Production, --device "Simulator Name"
```
